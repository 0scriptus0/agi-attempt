# Open Problems

The current architecture is a research hypothesis, not a solved AGI system.

## Memory problems

- retrieval failure on rare but important memories,
- memory poisoning,
- semantic deduplication mistakes,
- loss of exceptions during compression,
- contradiction resolution,
- temporal reasoning,
- stale memories.

## Reasoning problems

- inefficient test-time computation,
- premature commitment,
- reflection without real correction,
- hallucinated certainty,
- failure to recognize missing information.

## Agent problems

- long-horizon drift,
- tool misuse,
- repeated failed actions,
- reward hacking,
- termination failures.

## Learning problems

- deciding what deserves global updates,
- generalizing safely from few experiences,
- learning without destabilizing existing skills,
- separating user preference from objective knowledge.

## Evaluation problems

We need long-running benchmarks that measure whether the system genuinely improves from experience rather than merely accumulating more context.
