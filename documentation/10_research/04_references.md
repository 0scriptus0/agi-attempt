# Research References

This is the initial reference set behind the architectural ideas documented in this repository. It is intentionally separated from the design documents so the architecture can evolve without rewriting historical source notes.

  https://arxiv.org/abs/2305.10601

## Project interpretation

These sources support the general architectural direction, but they do not prove that the complete architecture described here achieves AGI. The project documentation should preserve that distinction.
