# Lewi 1 documentation

This directory contains the current static documentation surface for Lewi 1.

The docs intentionally separate:

- implemented runtime behavior;
- training and evaluation evidence;
- research-backed architectural direction;
- planned work;
- explicit limitations.

The current page is designed as a single long-form documentation surface so `/docs/` can stay simple to deploy while still providing anchors for every major subsystem.

The benchmark-style numbers on the page come from the repository's committed training and dataset artifacts. The page does not use the earlier landing-page placeholder metrics.
